ML Prediction System

Cross-League Sports Career Modeling

Overview

Developed a comprehensive machine learning system that predicts athletic career longevity across three major professional sports leagues: NFL, NBA, and FIFA. The system analyzes physical attributes, performance metrics, and positional data to forecast career trajectories over a 10-year span.

Key Features

  • Multi-Sport Dataset: 1,800+ athletes analyzed across NFL, NBA, and FIFA
  • Hierarchical Encoding: Custom position encoding capturing cross-sport similarities
  • Model Optimization: GridSearchCV tuning for Random Forest & Gradient Boosting
  • Interactive Dashboard: Dash application with real-time career trajectory visualization

Tech Stack

Python Scikit-learn Pandas Dash Plotly
