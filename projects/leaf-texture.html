Project Overview

This project analyzes natural leaf-surface patterns using computational image-based techniques to translate biological surface variability into engineering-relevant metrics. The PlantVillage tomato leaf dataset was originally built for agricultural disease detection, but its 10 texture classes are reinterpreted here as natural surface-pattern states — bridging biomimetic surface engineering with plant pathology through a single, shared computational pipeline.

Key Achievements

  • Fused 1,351-dimensional feature vectors per image — 60 GLCM texture features, 1 fractal dimension, 10 vein-geometry metrics, and 1,280 MobileNetV2 CNN embeddings
  • Trained a MobileNetV2-based classifier reaching ~92% validation accuracy across 10,000 training / 1,000 validation images
  • Reduced the combined feature space with PCA to 50 components (~95% explained variance), then applied K-means and Ward-linkage hierarchical clustering to discover natural texture groupings
  • Built a dual-application framework mapping each disease/texture class to an engineering surface analogy — from 'polished' to 'sandblasted' to 'honed' surfaces

Dual-Application Framework

The same computational pipeline serves two purposes at once: classifying tomato leaf disease states, and extracting quantitative surface-texture descriptors that translate to engineering design.

🌱 Agricultural Disease Detection

A fine-tuned MobileNetV2 classification head assigns each 224×224 RGB leaf image to 1 of 10 categories (9 disease states + healthy), reaching ~92% validation accuracy at ~15ms inference per image on GPU.

⚙️ Engineering Surface-Texture Analysis

Multi-modal feature extraction (GLCM + fractal + vein geometry + CNN embeddings) feeds PCA and K-means/hierarchical clustering to surface quantitative roughness, anisotropy, and complexity descriptors for biomimetic design.

💡 Why Dual Application Matters

Disease-only classification is a black box (label only). Pairing it with interpretable engineering features gives continuous, quantitative severity metrics instead of a discrete present/absent label — and lets the same pipeline generalize to manufactured-surface inspection.

🔗 Disease-Texture Correlation

Healthy leaves map to a low-contrast, regular-vein 'polished surface' profile; Late Blight maps to a high-contrast, irregular 'sandblasted surface' profile — showing that disease severity and engineered-surface roughness move together.

Feature Extraction Pipeline

📐 Gray-Level Co-occurrence Matrix (60D)

Contrast, correlation, energy, homogeneity, and entropy computed at 3 distances × 4 angles (0°/45°/90°/135°), giving a roughness and directional-anisotropy proxy analogous to profilometry Ra/Rq.

🌀 Fractal Dimension (1D)

Box-counting algorithm over 20 log-spaced box sizes (2-128px) estimates multi-scale surface complexity — from D≈1.0 for smooth vein networks to D≈2.0 for space-filling, irregular disease textures.

🍃 Vein Geometry (10D)

CLAHE contrast enhancement → Canny edge detection → morphological skeletonization extracts vein density, length, branch points, and dominant orientation — analogous to groove density in engineered lubrication textures.

🧠 MobileNetV2 CNN Embeddings (1,280D)

ImageNet-pretrained MobileNetV2 with global average pooling (top removed) captures hierarchical, non-linear pattern representations that complement the hand-crafted GLCM/fractal/vein features.

Preprocessing & Unsupervised Analysis

  • Background removal: HSV green-channel masking with morphological open/close cleanup, isolating leaf tissue from background before feature extraction
  • Noise reduction: 5×5 median filtering removes acquisition noise while preserving vein edges critical for geometry analysis
  • Dimensionality reduction: StandardScaler + PCA (50 components, ~95% variance retained) compresses the 1,351-dimensional feature space into a tractable texture space for clustering
  • Clustering: K-means (k=5, k-means++ init, 100 restarts) and Ward-linkage hierarchical clustering both applied, with k selected via elbow method and silhouette score
